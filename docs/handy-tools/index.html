Data Digitiziar

A self-contained browser digitizer for plot images. Upload a figure, define the plot area, calibrate the axes, and extract points or color-matched curves entirely in the browser.

Image workspace

Upload a plot image, then drag to define the plot box. Click inside the box to add manual points, then place one seed point on the target curve before running auto extraction.

Ready Upload an image to begin.

Axis calibration

Axis scale

The plot box can be set manually on the canvas. Add an orange legend exclusion box when the legend overlaps the plot. Use log scale only with positive axis limits.
